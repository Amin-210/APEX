# Targeting Patterns Library (copy techniques per mind-map layer)

How winning pages turn each layer of the customer map into copy. Updated after every analyzed winning page.

Status per pattern:
- **CORE** = seen in most analyzed winning pages (3+ pages and more than half where it could apply) or won an own test → always apply
- **CORE candidate** = seen in every analyzed page so far but fewer than 3 pages → apply by default, confirm with the next page
- **VARIANT** = works in specific categories/markets → apply when the condition matches
- **OPTIONAL** = seen once (or in a minority of pages) → idea, not a rule
- **TEST** = winners disagree → A/B test in the user's store

"Seen in" lists the analyzed pages. "Own test" records results from the user's stores (the strongest evidence).

**Product type matters (see customer-mind-map, Step 0):** patterns marked *(problem products)* apply to PROBLEM / LOSS products (body, skin, health, pain - something was lost or hurts). For DESIRE / LIFESTYLE products (gadgets, décor, entertainment - nothing was lost, the buyer wants a new pleasure) use the *desire version* given in the same row.

Pages analyzed so far: 5
1. NorthPower / North Alpine - men's compression tank - US - 09/2026 - problem product
2. YURI - collagen overnight wrapping mask (cosmetics) - US - 09/2026 - problem product
3. Aurivo ReHears - red-light "hearing therapy" neckband (senior health device) - US (German-run) - 09/2026 - problem product - 1000+ ads
4. Lumi Beam - smart mini projector (HY300-style white label), movie / gaming / cozy reading ambiance - US/UK/EU/AU (likely UK-run) - 09/2026 - DESIRE product - running ~10 months, several landing pages, clone domains
5. le D'affaires - 5-in-1 rotary cheese grater (white-label kitchen prep tool) - US - 09/2026 - MIX product (chore relief + "cooking fun again") - 1000+ ads, brand name used by Amazon/Walmart sellers

## Don't copy (seen on winning pages, still wrong)

| Pattern | Seen in | Honest alternative |
|---|---|---|
| Fake event timer / rolling "today only" deadline / "OFFER ENDS SOON" / "cart reserved for" timer | YURI, Aurivo, Lumi Beam | Real offer with a real end date, or gift with the bundle |
| Pre-checked subscription box | YURI | Unchecked or none (COD: causes refusals) |
| Changing / inflated compare-at prices ("1% OFF", anchors nobody paid) | YURI, Aurivo, Lumi Beam | Real single price as anchor |
| Inconsistent customer/review numbers  | NorthPower, YURI, Aurivo, Lumi Beam | One real number, real average |
| Price image in the wrong currency / price differing across the page | Lumi Beam ($ image for € visitors) | One consistent currency and price |
| "Self-test clinical" / survey stats, unexplained "3X", invented "clinically tested" badges and institutes | YURI, Aurivo | Only real results with a source |
| Fake mechanism words / false biology / "patented technology" on a generic white-label product / "the Original" when it isn't | NorthPower, Aurivo, Lumi Beam | Real mechanism in simple words; real differences of YOUR offer |
| Spec and performance overclaims (daylight brightness, "works on any surface", inflated lumens) | Lumi Beam | Say the real condition ("best in a dim room") - prevents refusals and returns |
| "Replaces your TV / monitor" when it doesn't really | Lumi Beam | "A big screen for your bedroom without buying a second TV" |
| Disease-treatment claims ("restores hearing", "cures tinnitus") | Aurivo | Only claims the product can back; supplements: "supports" + real ingredient evidence |
| Telling buyers to stop or replace a medical treatment ("drop your hearing aids") | Aurivo | Never. Add "talk to your doctor". |
| Fake media / university quotes and logos (Harvard, Healthline...) | Aurivo | Link real studies, or leave the section out |
| Stock-photo "doctor" as developer / endorser | Aurivo (likely), YURI (unclear) | Real named expert who agreed, or nothing |
| Disclaimer that contradicts the claims (FDA "not intended to treat" under treatment claims) | Aurivo | Claims must fit the disclaimer |
| Brand-written reviews | NorthPower, YURI, Aurivo, Lumi Beam (generic testimonials) | Real customer words, lightly edited |
| Guarantee that cannot be used (returns only to China, no reply, 20% "refund" offers) / contradicting guarantees ("Lifetime" next to "30 days") | Aurivo, Lumi Beam | One clear guarantee you honour. COD: check before paying; easy local return |
| Ads / bundles promising more than delivered (gift packs that never arrive) | Aurivo, Lumi Beam | Ad promises = page promises = what arrives |
| Unlicensed IP in bonuses ("scenes inspired by" famous book/film worlds) | Lumi Beam | Generic scenes / content you own |
