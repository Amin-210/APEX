# Customer Mind Map (the brain of the page)

The NorthPower page converts because it is **not built around the product - it is built around a map of the customer's mind**. Every section answers one point of that map; the product only appears as the solution.

This skill builds that map for any product. **Run it before every other page skill**, then pass its outputs to them (Part G).

**Where it sits in APEX:** **customer-mind-map** → page-engine (copy, review frames, image prompts) → persuasion-check → copy-voice-check → build. Page-engine Phase 2 runs this skill.

## Honesty and evidence rules (always)

- Every line in the map carries an evidence tag:
  - **[VOC]** real customer words (reviews, COD calls, WhatsApp, comments the user provided or that were found)
  - **[RESEARCH]** found in real sources (competitor reviews, forums, comments) via search
  - **[HYPOTHESIS]** reasoned guess - must be verified with real customers
- If web search is available, research real sources first (see Part H). If not, build the map from the user's data + clearly tagged hypotheses, and give the validation plan.
- Never invent customer quotes and present them as real.
- Use the map to show customers what is **true** about the product in their words - never to invent problems, deepen shame, or promise results the product can't give. For body-image, weight or health products: speak to comfort, confidence and feeling good, never push extreme body shame or unrealistic results, and never target minors.

## Reference libraries (ALWAYS read first)

This skill learns from every winning page analyzed. What it learned lives in two files next to this SKILL.md:

- **references/targeting-patterns.md** - proven copy techniques per map layer, with status (CORE / CORE candidate / VARIANT / OPTIONAL / TEST), where they were seen, the user's own test results, a "Don't copy" list and COD rules. When building a map and the page brief: apply all CORE patterns (and CORE candidates by default), the VARIANT patterns whose condition matches the product type and market, suggest fitting OPTIONAL/TEST patterns, and never use anything from "Don't copy". Prefer patterns with "Own test" wins.
- **references/winning-maps.md** - reverse-engineered customer maps of every analyzed winning page. Read the entries for similar categories / product types as inspiration for hypotheses (tag them [HYPOTHESIS], never [VOC]).

**Check before every run:** if the references folder or either file is missing, tell the user in one sentence that the trained library isn't installed (the skill then works without the learned patterns) and suggest reinstalling the plugin.

## Inputs to collect (ask only for what's missing)

1. Product + what it really does (supplier/Amazon bullets are fine)
2. Market: country, language, city type (e.g. Lebanon - Beirut, spoken Lebanese; Kenya - Nairobi, Kenyan English/Swahili)
3. Price, offer (e.g. 2+1), payment (COD?), delivery time, return policy
4. Any real customer data: reviews, COD confirmation-call notes, WhatsApp messages, ad comments

## Step 0 - Problem product or desire product? (decide first)

Before filling the map, classify the product - it changes how layers 2-4, 6 and 10 are filled and which library patterns apply:

| | PROBLEM / LOSS product | DESIRE / LIFESTYLE product |
|---|---|---|
| Examples | body shaping, skin, gut health, hearing, pain, sleep | projector, gadgets, décor, entertainment, fun kitchen tools |
| Layer 2 (problem) | the pain / flaw in their slang | the boring gap: small room, tiny screen, bare wall, "nothing to do" - plus mood / vibe words |
| Layer 3 (hidden habits) | hiding, covering, avoiding | the poor substitute they use today (phone in bed, YouTube fireplace videos) |
| Layer 4 (moments) | when it hurts | when they want the pleasure (weekend evening, rainy day, bedtime) |
| Layer 6 (deep desire) | restore what was lost ("reclaim / again") | escape / transformation of an ordinary space or moment |
| Layer 10 (impress) | "someone noticed" + family pride | shared-fun moment (partner, kids, friends enjoying it together) |
| Peak line | "[moment]. FINALLY." | "pov: [the moment]" / "this is my [evening] now" |
| Speed | instant result (appearance) or honest weeks timeline (health) | setup speed ("ready in seconds") |

Patterns marked *(problem products)* in targeting-patterns.md apply only to the left column; use the desire version given in the same row for the right column. Many products mix both (e.g. a massager = pain relief + evening ritual; a car fan = escaping the heat (problem) + a comfort gadget; kitchen and cleaning tools = chore relief (problem side: slow, tiring, messy, unsafe) + "fun again / feel like a pro" and a family moment (desire side)): fill the map from the side that drives the purchase and borrow the other side's moments for reviews. State the choice at the top of the output.

Also check **market sophistication**: if the product is viral / sold everywhere (stage 5), plan for (a) repositioning into a new use + tribe rather than a new mechanism, and (b) an honest "why buy from us" answer to "I can get this cheaper" (see targeting-patterns, layers 7 and 9).

## Part A - The 10-layer customer map (main table)

Always output this table, filled for the product:

| Layer | What we know (in the customer's words where possible) | Evidence | Where it goes on the page |
|---|---|---|---|
| **1. Who** | age range, gender, life stage, body/lifestyle, city type, income feel | | Gallery models, review casting, avatars |
| **2. The problem, in their words** | 5-10 real phrases/slang they use for it | | Icon grid, verdict grid |
| **3. Hidden habits** | what they secretly do because of the problem (hide, avoid, compensate) | | Reviews ("private problem" part) |
| **4. Painful moments** | exact situations when it hurts (places, events, times of day, seasons) | | Reviews, "[moment]. FINALLY.", ad hooks |
| **5. Surface desire** | the visible/practical change they want | | Headline, icon grid |
| **6. Deep desire** | how they want to FEEL | | Headline emotion, "Reclaim" headline, review endings |
| **7. Identity** | who they want to be / NOT be (what would bruise their ego, e.g. "shapewear") | | Product name, category rename, tone |
| **8. Fears / objections** | every reason not to buy (works? noticed? comfort? fit/dose? age? scam? delivery?) | | Review casting, accordions, FAQ, guarantee, COD line |
| **9. Failed solutions** | what they tried and why it failed (effort, time, cost, side effects) | | "The moment you put it on", mechanism section |
| **10. Who they want to impress** | partner, children, parents, colleagues, friends, themselves in the mirror | | "Someone noticed" in every review |

Then state the **key insight** in one sentence: the single emotional truth the whole page is built on.

### Reference example - NorthPower

| Layer | What they knew | Where on the page |
|---|---|---|
| Who | Men roughly 27-55, regular bodies, not gym people | Gallery models, review ages 27-55 |
| Problem in his words | "Dad bod", "beer belly", "man boobs", "love handles" | Icon grid, verdict grid |
| Hidden habits | Hides under baggy shirts, wears two layers, avoids mirrors and photos, buys suits too big | Reviews (Jake, Ryan, Brandon, Dave) |
| Painful moments | Getting dressed, summer, the beach, family photos, events, the office camera | Reviews, "Shirt fits. Finally." |
| Surface desire | Look slimmer, flatter belly, clothes that fit | Headline, icons |
| Deep desire | Feel confident, in control of his body again, proud, seen | "Confidence, Shape & Control", "Reclaim", "Dad, you look like a boss" |
| Identity | A strong man again, not someone "wearing shapewear" | "Power", "weapon", "vest" instead of "shapewear" |
| Fears / objections | Does it actually work? Will people notice? Is it hot? Will it fit? Am I too old? Is it a scam? | Reviews (one objection each), accordions, FAQ, guarantee |
| Failed solutions | Diets and gym take time, baggy clothes only hide | "The moment you put it on", "instant", no effort |
| Who he wants to impress | Girlfriend, wife, son, colleagues, himself in the mirror | Every review has "someone noticed" |

Key insight: the page is built around the man's lost confidence, not around a compression shirt.

## Part B - The 3 levels of wanting

Always output:

| Level | Question | This product |
|---|---|---|
| **1. Functional** | What should the product DO? | |
| **2. Emotional** | How do they want to FEEL? | |
| **3. Identity / social** | Who do they want to BE, and who should SEE it? | |

Reference:

| Level | NorthPower | Gut-health supplement |
|---|---|---|
| Functional | Flatten belly, hold in chest | Less bloating, better digestion |
| Emotional | Confident, not ashamed, in control | Light, comfortable, not embarrassed after eating |
| Identity / social | A strong man his family is proud of | Someone who enjoys meals with friends and closes her jeans without thinking |

Rule: **Amazon sells level 1. A converting page sells levels 2 and 3 and uses level 1 as proof.** People buy for levels 2-3 and justify with level 1.

## Part C - Psychological portrait (detailed image of the customer)

Write a vivid, concrete portrait (350-600 words) of the primary customer, covering:

1. **Name, age, place, life** - job, family, daily routine, city (local and realistic for the market).
2. **A day with the problem** - the exact moments it shows up, from morning to night.
3. **The mirror moment** - the private moment they feel the problem most, in their inner voice.
4. **Inner monologue** - 3-5 thoughts in their own words and dialect (+ English back-translation if not English).
5. **Public reason vs. secret reason** - what they would say out loud vs. the real reason they buy.
6. **Shame and pride** - what they hide, what they'd love to show.
7. **What they already tried** and how that failure made them feel (skeptical? tired? hopeless?).
   - **Secret stigma of the known solution** - what they hate about being SEEN using the standard fix (shapewear, a 10-step routine, a hearing aid, "diet pills"). The page must position the product as NOT that thing (name, look, category word). Seen in all analyzed winning pages.
8. **Trust barriers** - past bad experiences (fake products, scams, paying and not receiving), especially for COD markets.
9. **Buying trigger** - the event that makes them order now (a wedding, summer, a photo, a comment, payday).
10. **Decision style** - impulsive or careful? Do they ask someone first (spouse, friend)? Price sensitivity.
11. **Awareness level** (Eugene Schwartz): unaware / problem-aware / solution-aware / product-aware / most aware - and what that means for the first screen.
12. **Market sophistication** - have they seen many similar products/claims? If yes, they need a new real mechanism or a new angle, not bigger promises.

Then add **2-3 sub-personas** (different age / situation / main objection), one line each - these become the review casting and ad angles.

## Part D - Customer language bank

Lists of real phrases (tagged by evidence) for copy:
- **Problem words / slang** (their words, not clinical)
- **Desire words** (how they describe the result they want)
- **Trend word for the dream result** - the community / TikTok name for the outcome (e.g. "glass skin"), if one exists in this market. If yes, use it consistently as the end result across headline, icons and section titles
- **Emotional words** (shame, relief, pride - in their dialect)
- **Painful-moment phrases** ("when I sit down", "after lunch", "in photos")
- **Words to AVOID** - clinical terms, category words that bruise the ego, formal/translated phrases, anything that sounds like a scam in this market

For non-English markets write in the natural spoken register (e.g. clean, light Lebanese Arabic) + English back-translation.

## Part E - Objection ranking

Table: objection | how strong (1-5) | evidence | where the page answers it (review / accordion / FAQ / guarantee / COD line / video).
Always include for COD markets: scam fear, pay-before-delivery fear, product quality fear, delivery time.
Always add the **first-use shock**: what will surprise or worry them the first time they use the product (a strange texture, a tingle, early bloating with a probiotic, a detox feeling, a fan that is louder on max)? Answer it in the FAQ before it turns into a refund or a refused COD delivery.

## Part F - Angles

List the viable marketing angles derived from the map (villain/root-cause, feeling, symptom stack, day-in-life, benefit ladder, identity, social moment), one line each with the map layer it comes from. Present all angles and let the user choose before writing ads or page copy.

## Part G - Page brief (hand-off to the page)

Output a short brief that the page uses directly. The rows name page parts; in APEX, page-engine
writes all of them from this brief (a row for a part the page does not have is skipped):

| Section skill | Inputs from this map |
|---|---|
| product-title-formula | Core-desire word (→ product name), emotion + physical result + control/freedom word (headline), real mechanism, category renamed to ego-friendly word, 3 benefits pride→pain, the 4 icon-grid problems in their slang, COD trust line need |
| image-prompt-psychology | Casting brief for images (core persona + 1-2 sub-personas: age, body, look by market, clothes, home level, who is beside them), pain / relief / identity / shared moments as scenes, failed solution for the comparison slide, true tags available |
| bundle-offer-selector | Consumption time per unit ("each pack lasts X") or, for durable goods, the accessories / people that complete the experience (completion or family framing), realistic course length for results, price sensitivity + decision style (Part C), COD trust barriers, who they might buy extra units for |
| ugc-video-proof-row | Demo action, main pain story, unboxing/COD moment, age mix, local settings |
| trust-bar-accordions | Tribe word for the trust bar, fear-removing accordion titles from the objection ranking |
| mechanism-reclaim-section | "Reclaim" emotion, small realistic everyday desire (qualifier), 3 results outside→body→identity |
| proof-logic-block | The #1 failed solution category and its exact flaw in their words, its real price (for the anchor), honest result milestones (day 7 / 30 / 90) or setup speed for gadgets, cheap copies sold elsewhere (why buy from us), who it's for AND not for |
| how-to-use-steps | First-use shock + complexity fear (Part E), the real steps of first use / assembly / routine, the moment it can fail (suction, fit, dose, timing), the result of each step in their words |
| secret-weapon-verdict-grid | The #1 enemy, 4 problems in slang, 2 life payoffs, the "[everyday moment]. FINALLY." line |

| brand-trust-section | COD trust barriers and scam fears in their words (Part C, Part E), who the customer is (so team and story feel close), language bank for the promises and the About story |

Rule: every section's copy must trace back to a line in the map. If a section has no map input, the map is incomplete - go back and fill it.

## Part H - Research and validation plan

When real data is missing, give a concrete plan:
1. **Competitor and marketplace reviews** (Amazon, AliExpress, Trustpilot, local marketplaces): 5-star for desires and results, **3-star for objections** ("it works, but..."), 1-star for fears. Copy exact phrases.
2. **Free-talk places**: TikTok/Instagram comments under similar ads, Reddit/forums, YouTube comments, local Facebook groups (in the market's language).
3. **Competitor ads**: long-running ads in Meta Ad Library / TikTok Creative Center, their angles, and what nobody says (the gap).
4. **Own customers (COD advantage)** - add to confirmation call / WhatsApp:
   - What made you order this? (trigger)
   - What was bothering you most before? (problem in their words)
   - What have you already tried? (failed solutions)
   - What almost stopped you from ordering? (objection)
   - After delivery: What changed? Did anyone notice? (results, social proof)
5. After 20-30 answers, update the map: replace [HYPOTHESIS] lines with [VOC], and re-run the section skills where the map changed.

## Output order

1. Missing-input questions (only if essential; otherwise proceed with tagged hypotheses)
2. Step 0 - product type (problem / desire / mix) + sophistication stage
3. Part A - 10-layer map + key insight
4. Part B - 3 levels
5. Part C - psychological portrait + sub-personas
6. Part D - language bank
7. Part E - objection ranking
8. Part F - angles (user chooses)
9. Part G - page brief for the section skills
10. Part H - research/validation plan (what to verify first)
